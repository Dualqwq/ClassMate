# ClassMate V5：题目上下文加载方案

## 目标

V5 面向“写作业”和“期末复习”场景优化回答依据。只要工作区中存在当前题目的题目文件或代码文件，系统会更倾向于把问题识别为需要工作区内容的编程问题。

## ContextMode

规划结果除了 `requestType`，还会给出 `contextMode`：

- `none`：普通闲聊，不自动读取文件。
- `active_file`：读取当前代码及同名源文件/头文件。
- `problem_context`：读取当前题目的完整相关上下文。
- `debug_context`：读取题目、代码、构建文件、测试和说明文件。
- `edit_context`：读取要修改的代码及直接相关文件。

运行时控制器会保证任务所需的最低上下文范围。模型不能通过返回 `none` 来取消思路题、调试题或代码修改所需的文件。

## 当前题目目录

1. 识别以下精确文件名：`question`、`problem`、`问题`、`题目`、`作业说明`、`assignment`，支持 `.md`、`.markdown`、`.txt`、`.pdf`。
2. 如果只有一个题目文件，确定性选择该文件；如果有多个，则选择目录树上距离当前活动文件最近的一个。
3. 将题目文件所在目录作为题目根目录。
4. 如果题目文件位于整个工作区根目录，而当前代码位于子目录，则使用当前代码目录，避免把其他作业一起加载。
5. 多轮对话默认继承上一轮题目根目录、已加载文件、问题类型和上下文模式；只有用户明确表示“换一题”等情况才切换。

## 首轮 RouteAndPlan 上下文

首轮规划仍始终接收经过截断和排序的工作区清单。为了让模型能判断“这里是否是一个作业文件夹”，还会按以下规则附带受控的文件正文：

1. 当前候选范围（没有已选题目和活动文件时即整个工作区）不超过 20 个受支持文件且总大小不超过 300 KiB 时，附带该范围内全部文件。
2. 否则，如果活动文件所在的直接目录不超过 10 个受支持文件且总大小不超过 200 KiB，附带该目录全部文件。
3. 最近题目文件和活动文件始终进入候选；若超过单文件安全上限则安全跳过，而不是突破读取限制。
4. RouteAndPlan 返回结构化的 `isAssignmentWorkspace`、`assignmentRoot` 和 `assignmentEvidence`。
5. 模型可以补充文件，但不能取消控制器确定性选择的题目、活动文件和小型作业目录。
6. 如果最终 Answer 所需文件已经全部存在于首轮预览中，直接复用已读取内容，不重复访问磁盘。

## 相关文件

`problem_context` 和 `debug_context` 会选择题目目录中的全部受支持文件，包括：

- 题目 Markdown 或 PDF；
- C/C++ 源文件与头文件；
- Makefile、GNUmakefile 和 `.mk` 文件；
- 文本说明、`.txt`、`.in`、`.out`、`.ans` 输入输出样例和测试数据。

不会按 5 个文件截断。文件数量不设固定上限。

以下内容不会作为题目正文加载：

- `node_modules`、`.git`、`dist`、`out` 等排除目录；
- 二进制文件、压缩包和不支持的文件类型；
- 其他题目目录；
- 超过单文件或总内容预算的低优先级可选文件。

## 安全边界

- 只能读取工作区清单中经过验证的精确相对路径。
- 禁止绝对路径、目录穿越和模型编造的路径。
- 题目文件和当前代码是必需上下文，优先于模型额外选择的文件。
- 不限制文件数量，但继续限制单个文件大小和所有文件的总内容大小。
- 可选文件超过预算时跳过，不会退化为读取整个工作区。
- 首轮正文只能来自经过验证的工作区清单，并受 20 文件/300 KiB 或 10 文件/200 KiB 的额外预算约束。
- 文件正文按“不可信数据”处理，不能覆盖系统指令。
- 若已判断为作业目录但正常选择最终加载为零，控制器会用题目文件、活动文件、同目录文件和上一轮文件做一次安全兜底；不会读取所有 Skill 参考文件。

## 数据结构题目知识卡片

工作区正文加载后，控制器会根据路径、题号、标题、特殊题面语句和代码特征执行本地门控。疑似为已收录的数据结构作业时，额外调用一次轻量题目识别 API，并且只允许从本地召回的候选 ID 中选择。

匹配达到置信度和独立证据要求后，只加载一张题目主卡和最多一个同题错误子卡。卡片在 Answer 中被明确标记为可选提示；当前题面和代码优先，调试结论必须由当前代码中的真实语句支持。题目指纹未变化的多轮追问复用上次结果，不重复识别。

完整设计与文件说明见 `docs/problem-knowledge-v5.md`。

## 主要实现文件

- `src/workspace/contextPolicy.ts`：上下文模式、题目目录和相关文件选择。
- `src/workspace/workspaceContextLoader.ts`：无文件数量上限的安全加载。
- `src/workspace/workspaceContextProvider.ts`：最近上级题目文件识别。
- `src/graph/ClassMateGraphRunner.ts`：任务类型偏置、上下文模式和会话上下文。
- `src/chat/ChatSession.ts`：按会话保存上一轮题目上下文。
- `src/prompts/routeAndPlanPromptBuilder.ts`：把 `contextMode` 加入规划输出。
- `src/problemKnowledge/`：题目门控、候选检索、卡片索引和正文加载。
- `src/prompts/problemIdentifierPromptBuilder.ts`：构造受限的题目识别调用。
- `src/prompts/answerPromptBuilder.ts`：把命中卡片作为可选参考提交给 Answer。
