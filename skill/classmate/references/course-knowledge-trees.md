# 三门课程树状知识结构

本文件基于 `course-knowledge-system/` 中已有整理进一步结构化，目标是提供类似“课程知识树”的材料，方便后续写入 skill 或做知识点检索。

每个知识点尽量包含：

- 定义
- 前置知识
- 后续应用
- 易混淆概念

│   │   └── 易混淆概念：重载不能改变运算符优先级和结合性；不能创造新的运算符；语义应符合直觉。
│   ├── 5.3C 友元

│   │   ├── 后续应用：输入输出运算符重载、跨类协作、测试辅助函数。
│   │   └── 易混淆概念：友元不是成员函数；友元会削弱封装，通常只在必要时使用。
│   ├── 5.3D 静态成员/静态成员函数

│   │   ├── 前置知识：类、对象、作用域、成员访问。
│   │   ├── 后续应用：对象计数、共享配置、工厂函数、类级工具函数。
│   │   └── 易混淆概念：静态成员函数没有 `this` 指针；静态成员变量通常需要类外定义。
│   ├── 5.3E 常量成员/常量成员函数
│   │   ├── 定义：常量成员创建后不可重新赋值；常量成员函数承诺不修改对象状态。
│   │   ├── 前置知识：`const`、类、成员函数、初始化列表。
│   │   ├── 后续应用：只读接口、常量对象访问、接口安全性。
│   │   └── 易混淆概念：常量成员必须在初始化列表中初始化；常量对象只能调用常量成员函数。

│   │   ├── 定义：常量引用用于安全地引用对象且不修改它；右值引用用于绑定临时对象并支持移动语义。

│   │   ├── 定义：在继承体系中，派生类对象可以转换为基类类型；基类指针或引用在条件满足时可转回派生类类型。

        定义：移动拷贝通常指移动构造函数，用一个即将不再使用的对象创建新对象时，不复制其资源内容，而是把资源所有权“转移”给新对象。

        5.9移动赋值
        定义：移动赋值通常指移动赋值运算符，用一个即将不再使用的对象给已有对象赋值时，先释放当前对象原有资源，再接管右侧对象的资源。

│       后续应用：资源管理类、容器元素重排、临时对象赋值、智能指针、Rule of Five。
│       易混淆概念：移动赋值 vs 拷贝赋值；已有对象赋值 vs 创建新对象；接管资源前要处理自身原有资源；自赋值和异常安全问题。
        5.10 `std::move`
        定义：`std::move` 把一个表达式强制转换为右值引用，表示“这个对象可以被移动资源”。
        前置知识：左值/右值、右值引用、移动构造、移动赋值。
│       后续应用：资源管理类、容器性能优化、智能指针所有权转移。
│       易混淆概念：`std::move` 本身不移动数据；真正的移动发生在移动构造或移动赋值中；被移动后的对象仍有效但内容不应再假设。
