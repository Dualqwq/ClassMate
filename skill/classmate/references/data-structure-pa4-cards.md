# 数据结构 PA4 题目卡

这些卡片是经过整理的候选参考。回答前必须核对当前版本题面、接口和学生代码。

## PA4 4-1-2 Game

### 主要方法

用 Dijkstra 求到每个点的最短时间，同时维护最短路方案数。若发现更短距离，覆盖距离和方案数；若发现相同最短距离，累加方案数并取模。点权可在进入新点时加入距离。

### 复杂度

正常邻接表加堆的 Dijkstra 约为 `O((N+M) log N)`。参考实现的邻接数组扩容会反复复制，建图最坏可能达到 `O(M²)`，必须把建图成本一起分析。空间 `O(N+M)`。

### 易卡点

- 堆里可能保留旧距离，弹出后要判断是否已经过期。
- 更短路径是覆盖计数，相同路径才是累加计数。
- 起点和终点的点权是否计入由题面决定。
- 不能只看 Dijkstra 正确就忽略建图超时。

## PA4 4-2-2 Pattern Matching

### 主要方法

先对大矩阵做行方向滑动哈希，再沿列方向组合，得到每个 `m×n` 窗口的二维哈希并计数。对每个小矩阵计算同样的哈希，在表中查询出现次数。

### 复杂度

大矩阵预处理 `O(MN)`，`k` 个模式直接计算为 `O(kmn)`，哈希查询期望 `O(1)`；总时间 `O(MN+kmn)`，空间 `O(MN)`。

### 易卡点

- 两个方向的进制、幂和减去窗口首项的顺序要一致。
- `unsigned long long` 与 `long long` 大小相同；它的作用是让溢出按模 `2^64` 有定义，不是节省空间。
- 单哈希有碰撞概率，是否需要双哈希或命中后二次核验取决于题目要求。
- 行列尺寸和滑动窗口边界容易写反。

## PA4 4-3-2 Component

### 主要方法

并查集维护连通块代表，每个代表结点关联一个左式堆，堆中只保留当前连通块最大的 `k` 个权值。合并连通块时先合并并查集，再合并两个堆并弹出多余的小元素；查询通过最新代表找到堆顶的第 `k` 大。

### 复杂度

并查集操作为摊还 `O(α(n))`，堆大小限制为 `k` 后，合并、插入和删除为 `O(log k)`，总时间约 `O((m+q)log k)`，空间 `O(n)`。

### 易卡点

- 并查集合并后，堆所有权必须转移到新的根。
- 不再是根的旧结点不能继续作为查询入口。
- 只保留最大的 `k` 个时，堆顶应代表这 `k` 个中的最小值。
- `k` 大于连通块大小时按题目要求输出失败值。

## PA4 4-3-3 Sort

### 主要方法

唯一合法信息来源是三元 `compare`：它返回三个编号中最大和最小，剩下的编号就是中间值。围绕这个原语设计排序过程，并单独统计真实 `compare` 调用次数。

### 复杂度

目标通常仍是比较意义上的 `O(n log n)`，但是否通过取决于三元比较实际调用常数和题目给定 `limit`，不能只写渐进复杂度。

### 易卡点

- 数组里保存的是编号，不能直接用编号大小代替对应元素大小。
- 中间元素可用“三个输入中既不是最大也不是最小的那个”确定。
- 必须处理重复值是否存在、接口如何规定相等。
- 参考答案含多套未经统一证明的实现，使用前要用随机对拍检查正确性和调用次数。
