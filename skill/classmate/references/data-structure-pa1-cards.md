# 数据结构 PA1 题目卡

这些卡片只提供候选方法和易卡点。先核对当前题面与代码；发生冲突时以工作区为准。按照当前提示层级逐步透露，不直接复制参考代码。

## PA1 1-1-1 filename

### 主要方法

这是只允许插入、删除且只关心答案是否不超过 `K` 的编辑距离问题。先判断两个字符串长度差；长度差已经超过 `K` 时可直接失败。否则只计算主对角线附近宽度为 `O(K)` 的状态，不建立完整二维表，并用滚动数组保存相邻两层。

### 复杂度

- 时间：`O((N+M)K)`。
- 空间：滚动后为 `O(K)`。

### 易卡点

- 偏移量（参考实现中的 101）只是把可能为负的对角线差映射成数组下标，不是题目常量。
- 每一层只有合法带宽内的状态可用，带外状态应视为不可达。
- 初始化第一行、第一列和滚动层时容易残留上一轮数值。
- 第一层提示应先说明“只算对角线附近”，不要直接给完整转移式。

## PA1 1-1-2 Interview-old

### 主要方法

用三个数组保存人员编号以及每个位置的左、右邻居，模拟循环双向链表。加入新人时先沿链表找到插入位置，再同时更新“左邻居的右指针、新人的左右指针、右邻居的左指针”。

### 复杂度

插入指针本身是 `O(1)`，但沿圆桌移动寻找位置不是。总移动次数为 `Σ(m mod i)`，最坏可到 `O(n²)`；参考说明中的 `O(mn)` 是较松上界。空间为 `O(n)`。

### 易卡点

- 不要把“链表插入快”误解为“按位序找到插入点也快”。
- 初始只有一人时，左右邻居都指向自己。
- `people`、`left`、`right` 的下标含义必须统一，不能混用人员编号和结点位置。
- 参考代码存在格式化读入类型需要复核，不能无条件照搬。

## PA1 1-2-1 Gift

### 主要方法

将 `n≤40` 的选择拆成两半，分别枚举每一半的所有花费和。排序右半部分；对左半每个和，二分统计右半中满足预算的项。这是折半搜索。

### 复杂度

- 枚举与排序：`O(n·2^(n/2))`。
- 空间：`O(2^(n/2))`。

### 易卡点

- 单个价格能放进 `int`，不代表半边总和、预算差或方案数不会溢出。
- 每件礼物必须二选一，枚举分支不能漏选或多选。
- 二分边界应表达“右半花费不超过剩余预算”。
- 原参考文字写“改用 int”是笔误，实际应结合范围考虑 `long long`。

## PA1 1-2-2 Graphics

### 主要方法

利用分隔线互不相交形成的一致顺序，先按端点坐标排序。对每个查询点，用叉积或 `ToLeft` 判断它位于某条线哪一侧，再二分定位所属区域。

### 复杂度

- 预排序：`O(n log n)`。
- 每次查询：`O(log n)`。
- 总计：`O(n log n + m log n)`。

### 易卡点

- 叉积中的坐标乘法需要 64 位整数。
- 必须统一“在线上”属于哪一侧，否则二分会差一。
- 二分的真假方向依赖线的排序方向，不能背模板。
- 参考实现中相同的两次查询需要复核，不能自动视为正确。

## PA1 1-2-3 二维偏序

### 主要方法

先处理非正权值和重复坐标，再按一个维度排序，将问题转化为另一个维度上的最大权不下降子序列。使用能查询“坐标前缀最大值”的结构，并在当前位置更新最大收益。

### 复杂度

排序和每次前缀查询、更新均为对数级，总时间 `O(n log n)`，空间 `O(n)`。

### 易卡点

- 相同坐标可同时选择时，应合并它们的正权值，而不是任意丢掉。
- 非正权点通常不会提高答案，但删除前要确认题目是否要求必须选点。
- 相同 `a` 或 `b` 的排序与批量更新规则会影响“严格/非严格”关系。
- 参考代码在全为非正权和迭代器到末尾时可能有边界风险，应独立核对。
