# 数据结构 PA3 题目卡

这些卡片只用于补充已识别题目的方法和卡点，不替代对当前题面与代码的分析。

## PA3 3-1-2 Dance

### 主要方法

使用按子树大小定位的隐式 Splay 或其他可分裂合并的平衡树表示序列。插入通过分裂与合并完成；交换可定位两个结点后交换名字；区间翻转在拆出的子树上打懒标记；整体旋转只维护全局偏移。

### 复杂度

插入、交换、翻转均摊 `O(log N)`，整体旋转 `O(1)`，总时间 `O(M log N)`，空间 `O(N)`。

### 易卡点

- 访问子结点或按排名下降前必须下传翻转标记。
- 翻转跨过循环位置 0 时，应拆成两个普通区间或先换算全局偏移。
- Splay 的子树大小要在旋转、分裂和合并后及时更新。
- 只查到结点却不伸展，可能破坏预期的均摊性能。

## PA3 3-2-2 Kidd

### 主要方法

坐标范围极大时不要预建完整线段树。以大区间为根，只在操作真正覆盖到某个局部时动态分裂结点；整段覆盖时直接更新统计量和懒标记，部分覆盖时才创建孩子并递归。

### 复杂度

参考方案期望单次 `O(log n)`、总时间 `O(m log n)`，每次操作只增加常数个分裂结点时空间可控制在 `O(m)`。但树是否始终具有对数深度要结合实际分裂规则验证，不能把期望复杂度说成无条件最坏界。

### 易卡点

- 新建孩子时必须继承父区间原有的均匀值和懒标记。
- 部分覆盖前先下传，返回后再汇总父结点。
- 区间端点的开闭规则必须统一。
- 不要用 `n` 个结点初始化巨大坐标范围。

## PA3 3-3-3 Nearest Neighbor

### 主要方法

KD 树在各层轮换划分维度，按当前维度的中位数把点分到左右子树。查询时先进入更接近查询点的一侧，并维护当前最优距离；只有分割平面另一侧仍可能出现更近点时才回溯。

### 复杂度

若每层重新排序，建树为 `O(n log² n)`；使用线性选中位数可以进一步优化。最近邻查询通常较快、期望接近 `O(log n)`，但退化数据下最坏仍可能访问 `O(n)` 个点。空间 `O(n)`。

### 易卡点

- 剪枝比较的是“查询点到分割平面的距离”和“当前最优距离”。
- 为避免开方，应统一比较距离平方。
- 相等距离时如何选点必须遵守题目要求。
- 维度轮换、左右区间和中位数是否重复放入子树容易出错。
