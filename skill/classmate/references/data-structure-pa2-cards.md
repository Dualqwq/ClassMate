# 数据结构 PA2 题目卡

这些卡片是可选参考。先依据当前题面和代码判断，不要把旧版本答案强加给学生。

## PA2 2-1-2 Risk

### 主要方法

利用窗口左边界单调移动的性质，用单调队列预处理每天窗口最大值或预警人数。随后排序预处理结果，对每组查询用二分统计落在范围内的天数。

### 复杂度

- 单调队列：`O(n)`。
- 排序：`O(n log n)`。
- `T` 次查询：`O(T log n)`。
- 总时间：`O(n log n + T log n)`；空间 `O(n)`。

### 易卡点

- 队首负责淘汰过期元素，队尾负责保持单调性，两种弹出原因不能混。
- `m`、`p/q`、窗口边界计算和中间乘加可能需要 `long long`。
- 只看每个输入变量范围不足以判断中间表达式是否溢出。

## PA2 2-2-2 Polynomial

### 主要方法

先进行词法处理，把数字、变量、括号和运算符拆成 token，并在 `2x`、`x(x+1)` 等位置补隐式乘号。再用运算符栈把中缀表达式转成后缀表达式，最后用多项式栈求值。

### 复杂度

词法扫描和中缀转后缀应接近线性；若在字符串中反复 `insert`，可能退化为 `O(n²)`。多项式求值还取决于最高次数和幂指数，乘法通常与两个多项式次数乘积有关，不能只写无含义的 `O(n)`。

### 易卡点

- 先补乘号，再处理运算符优先级。
- 幂运算的结合性与普通加减乘不同。
- 一元负号、括号相邻、数字与变量相邻是常见 token 边界。
- 中缀转后缀阶段只处理结构，真正的多项式计算放到后缀求值阶段。

## PA2 2-3-2 Sect

### 主要方法

按依赖顺序分三步：先后序计算每个结点的子树内力和；再确定每个师父的正统弟子；最后沿正统关系计算或跳转寻找引路人。

### 复杂度

每个阶段若保证已处理结点可以复用，目标总时间为 `O(n)`，空间为 `O(n)`。对于“寻找引路人是线性”的结论，要说明为什么一个结点不会被多条路径反复完整扫描。

### 易卡点

- 不能假设输入顺序已经满足父子计算顺序。
- 区分“没有师父”“尚未计算”和合法的 1-based 编号，哨兵值不能冲突。
- 递归前先确认树深是否可能造成栈溢出。
- 正统弟子的比较规则相等时如何处理必须服从当前题面。
